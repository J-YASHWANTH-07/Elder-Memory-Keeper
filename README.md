# Elder Memory Keeper

A simple, large-text medicine reminder app for elderly users.
React + Vite frontend, FastAPI backend with in-memory mock data, packaged for Android with Capacitor.

```
Project/
├── backend/            FastAPI API (no database, in-memory data)
│   ├── app/
│   │   ├── main.py             app entry, CORS, router registration
│   │   ├── config.py           demo OTP, timing constants
│   │   ├── models.py           Pydantic schemas
│   │   ├── store.py            seeded mock data + in-memory state
│   │   ├── schedule_service.py dose status logic (upcoming/due/taken/missed)
│   │   ├── auth.py             bearer-token dependency
│   │   └── routers/            auth, medicines, schedule
│   └── run.sh                  creates venv, installs, starts on 0.0.0.0:8000
└── frontend/           React 19 + Vite 6 + Capacitor 7
    ├── src/
    │   ├── api/        client.js (live API + auto demo fallback), mock.js
    │   ├── context/    Settings, Auth, Schedule (polls every minute)
    │   ├── components/ BigButton, DoseCard, StatusBadge, BottomNav, ...
    │   ├── pages/      Login, Home, Schedule, Reminder, History, Settings
    │   ├── styles/     global.css (text size + high contrast tokens)
    │   └── utils/      time helpers
    ├── android/        generated by Capacitor
    └── capacitor.config.json
```

## Run locally

Backend (terminal 1):
```sh
cd backend
./run.sh            # http://localhost:8000  (docs at /docs)
```

Frontend (terminal 2):
```sh
cd frontend
npm install
npm run dev         # http://localhost:5173
```

Login with any 10-digit mobile number. Demo OTP is `123456`.

## Data source modes (Settings screen)

- **Auto** (default): uses the server, falls back to built-in demo data if the server is unreachable.
- **Server**: server only, shows an error if unreachable.
- **Demo**: built-in data only, no network needed.

## API

| Method | Path                     | Purpose                              |
|--------|--------------------------|--------------------------------------|
| POST   | /auth/request-otp        | `{mobile}` → message                 |
| POST   | /auth/verify-otp         | `{mobile, otp}` → `{token, user}`    |
| GET    | /medicines               | medicine list                        |
| GET    | /schedule/today          | today's doses with status + progress |
| POST   | /doses/{id}/taken        | mark taken, returns today's schedule |
| POST   | /doses/{id}/skip         | mark skipped                         |
| GET    | /history                 | last 7 days taken/missed counts      |

Protected routes need `Authorization: Bearer <token>`.

## Build the Android APK

Requires Android SDK and JDK 21 (Android Studio bundles one).

```sh
cd frontend
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
npm run android:apk
# APK: android/app/build/outputs/apk/debug/app-debug.apk
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

### Connect the phone to the laptop API

1. Phone and laptop on the same Wi-Fi.
2. Find the laptop IP: `ipconfig getifaddr en0` (macOS).
3. Start the backend with `./run.sh` (binds to 0.0.0.0).
4. In the app, Settings → Server address → `http://<laptop-ip>:8000` → Save.

If the server is not reachable the app keeps working on demo data.
